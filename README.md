# Map-Projection-Project
Final Year Project 2025-2026

## FrameWork and Libraries Used
* Qt: https://www.qt.io/
Will need to be installed, recommended to use the online installer: https://www.qt.io/download-qt-installer

* JSON: https://github.com/nlohmann/json
Included with fetchcontent within the cmakelist. No action required.

* Boost C++ (For Testing): https://www.boost.org/
Will need to be installed and built as a shared library: https://www.boost.org/doc/libs/latest/libs/test/doc/html/boost_test/adv_scenarios/build_utf.html

## Resources Used
* World Map: https://github.com/nvkelso/natural-earth-vector
Included as a git submodule. No action required.
* Pangea Map: https://services2.arcgis.com/xsh7pVZv42relbEf/ArcGIS/rest/services/Pangea/FeatureServer/4, https://developers.arcgis.com/rest/
